# Task Log（任务日志）功能

## Context

给「进行中 / 逾期」任务增加独立可写的**任务日志**，并引入可选的**严格进度机制**（进度不再按日期自动累进，只有当日写日志后才累计）。同时新增「日志」页统一管理。

进度模型按用户最新决定简化：**取消手动滑块**（进度不再可手动编辑，新建默认 0）；**长期任务没有进度信息**（无法计算）。进度全部改为**派生值**，收敛到一个 helper，便于用户后续自行微调。

## 数据模型（src/types.ts）

- `AppView` 增加 `'logs'`。
- `Task`：新增 `strictProgress: boolean`（默认 false）；**移除 `progress` 字段**。
- `EffState.progress` 改为 `number | null`（长期任务为 null）。
- 新增：
  ```ts
  export interface TaskLog {
    id: string
    taskId: string
    date: string            // yyyy-MM-dd
    content: string          // 原始文本；换行=新条目，行首 tab=缩进
    targetProgress?: number | null // 0..100，仅 strict 阶段任务
    createdAt: string
    updatedAt: string
  }
  ```

## 进度模型（新增 src/lib/progress.ts，收敛于此）

- `autoProgress(task, onDate): number`：`elapsed = clamp(diffDays(start,onDate), 0, total)`，`total = diffDays(start,end)`，`round(elapsed/total*100)`；`total<=0` 时返回 0。新建任务（onDate=start）→ 0。
- `taskProgress(task, logs, onDate): number | null`：
  - 长期任务 → `null`。
  - `strictProgress` → 该任务最新日志的 `targetProgress`，缺省则 `autoProgress(task, 该日志日期)`；无日志 → `0`。
  - 非 strict 阶段任务 → `autoProgress(task, onDate)`。
- 复用 `diffDays`/`toDate`（src/lib/dates.ts）。

## Store + 持久化

- `src/store/storage.ts`：`PersistedData` 增加 `logs: TaskLog[]`；`normalize` 兜底 `logs`（默认 `[]`，逐条补 `date`/`content`）；`loadData`/`parseImport` 校验数组；`exportJson` 带上 `logs`。
- `src/store/useStore.ts`：
  - 新增 `logs` + `addLog`/`updateLog`/`deleteLog`。
  - `NewTaskInput`/`addTask`：去掉 `progress`，增加 `strictProgress`。
  - 保存订阅同时比对 `projects`/`tasks`/`logs`。
  - 级联清理：`deleteTask`/`deleteProject` 删除相关 `logs`。
  - `useRows()` 把 `logs` 传给 `buildRows`。

## 进度接线

- `src/lib/tree.ts`：`effectiveStates(tasks, logs)` 叶子进度用 `taskProgress`；父级 = 子级非 null 进度均值（全 null 则 null）。`buildRows` 透传 `logs`。
- 消费端更新为派生进度并处理 null：
  - `src/components/gantt/TaskBar.tsx`（phase 分支用 `eff.progress`，long-term 走 isGoal 分支不受影响）。

  - `src/components/TaskDetailPanel.tsx`（长期任务隐藏进度条/百分比）。
  - `src/components/Sidebar.tsx`、`src/pages/StatisticsPage.tsx`、`src/pages/DashboardPage.tsx`、`src/pages/TasksPage.tsx`：进度读取改为 `effectiveStates`/`taskProgress`（长期任务跳过）。

## 文本格式（需求 7，src/lib/logs.ts）

- 存原始文本。展示用 `parseLogContent(content)`：按行拆分，数行首 `\t` 为 depth，去 tab 为文本；渲染 `· ` + `depth * 16px` 缩进。
- 编辑时原始文本原样放回 textarea。

## 日志页（新增 src/pages/LogsPage.tsx）

- `src/components/Sidebar.tsx` 在 gantt 下方插 `{ id: 'logs', label: 'Logs', icon: ClipboardList }`；`src/App.tsx` 加路由分支。
- 默认按日视图：日志按 `date` 倒序分组，每日列出该日所有任务日志。
- 任务树筛选：project → 一级 task → 二级…（资源管理器式）；「全部」。
- 支持查看 / 编辑 / 删除。
